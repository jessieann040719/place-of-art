IMPORTANT ABOUT NO-CODE EDITING
GitHub Pages cannot securely save logins, uploaded images, events or news by itself.
The admin interface is built, but to make Publish work across all devices:
1. Create a free Supabase project.
2. Run supabase-schema.sql in Supabase SQL Editor.
3. Create artist accounts in Supabase Authentication.
4. Link each user ID to the matching artists.user_id.
5. Create a private/public Storage setup for website images as appropriate.
6. Put the PUBLIC Supabase project URL and anon/publishable key into config.js.
7. Connect the provided admin/content code to the Supabase tables.
8. For deposits, connect Stripe or Square using secure server/webhook logic.
Never put secret keys in GitHub.
